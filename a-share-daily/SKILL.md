# A股每日收盘复盘技能

## Overview

本技能提供一套完整的 A 股每日收盘复盘工作流：从数据获取、多维度分析到生成单页 HTML 复盘报告。报告结构对标专业投顾复盘日报，涵盖大盘、资金、板块、技术面、风险预判全链路。

## 复盘时间

- **复盘时点**：每日 A 股收盘后（15:00 之后）
- **数据时效**：使用收盘后最新数据

## 数据源优先级

按以下优先级获取数据，优先使用已连接的 MCP 工具：

1. **通达信 MCP (tdx-connector)** — A股行情、K线、板块、个股、技术指标（已连接，首选）
2. **WebSearch** — 补充市场情绪、资金流向、板块涨跌、龙虎榜等
3. **东方财富/同花顺等公开数据源** — 通过 WebFetch 获取

## 复盘五大维度（固定框架）

每日复盘报告必须覆盖以下五个维度，缺一不可：

### 一、大盘整体复盘

**1. 主要指数涨跌**
- 上证指数、深证成指、创业板指、科创50、沪深300、北证50
- 每个指数需记录：收盘点位、涨跌幅、涨跌点
- 盘面特征描述：开盘走势、盘中高低点、收盘位置、指数间分化情况

**2. 量能情况**
- 两市总成交额（沪市+深市+北证）
- 与前一日对比，计算缩量/放量幅度及百分比
- 量价关系判断：缩量上涨/缩量下跌/放量上涨/放量下跌，及其含义

**3. 市场情绪指标**
- 上涨/下跌/平盘个股数量
- 赚钱效应（上涨个股占比）
- 涨停/跌停数量
- 炸板率
- 市场最高连板（个股+连板数）
- 情绪研判：恐慌/低迷/中性/活跃/亢奋

### 二、资金流向复盘

**1. 北向资金**
- 沪股通/深股通净流入/流出金额
- 融资融券净买入/卖出
- 北向重点加仓/抛售方向

**2. 主力资金**
- 全市场主力资金整体流向
- 主力净流入前10个股（排名、个股、金额）
- 主力净流出前10个股（排名、个股、金额）
- 板块资金流向：净流入/流出居前的行业板块

**3. 龙虎榜简要概况**
- 上榜个股数量、机构参与数量
- 机构净买入/卖出方向
- 知名游资动向（如有）

### 三、板块涨跌详情

**1. 当日领涨板块（Top 5）**
- 板块名称、上涨逻辑、板块龙头个股（含连板/涨停状态）

**2. 当日领跌板块（Top 5）**
- 板块名称、下跌诱因

**3. 题材轮动**
- 新晋热点：刚启动或持续走强的方向
- 衰退旧主线：资金撤离、退潮的方向

### 四、大盘技术面

**1. 上证指数关键价位表**
- 第一压力位、关键压力位、多空分水岭、当前收盘、核心支撑位、次级支撑位
- 每个价位附逻辑说明

**2. 各指数通道判断**
- 上证指数/深证成指/创业板指/科创50：当前位置判断 + 依据
- 整体技术面研判

### 五、风险提示 + 明日行情预判与操作参考

**1. 盘面现存风险点**（5-8条，每条一句话说明）

**2. 明日大盘走势预判**
- 综合研判（一句话结论）
- 利空因素 / 利好因素
- 预判方向：指数区间预估

**3. 明日重点关注主线板块（Top 3-5）**
- 方向、板块、逻辑、关注级别（重点关注/适度关注）

**4. 需要规避的高危板块（Top 3-5）**
- 方向、板块、风险、规避级别（规避/谨慎）

### 六、市场情绪周期位置（可选增强）

- 判断当前情绪处于：冰点期→回暖期→发酵期→高潮期→退潮期 的哪个阶段
- 连板高度、涨停家数趋势变化

### 七、ETF/指数增强策略参考（可选增强）

- 宽基ETF（510300、510500、159915等）当日表现
- 行业ETF异动

## HTML 报告生成规范

### 技术规范

1. **单文件自包含**：所有 CSS 内联在 `<style>` 标签中，不引用外部资源
2. **零依赖**：不使用任何 CDN 链接、外部字体、外部 JS 库
3. **响应式**：适配桌面端浏览，最大宽度 1200px，居中
4. **文件命名**：`A股复盘_YYYYMMDD.html`，如 `A股复盘_20260812.html`
5. **字符编码**：UTF-8，声明 `<meta charset="UTF-8">`

### 视觉规范

1. **配色方案**（中国A股惯例）：
   - 涨/利好 → 红色 `#e74c3c` 或 `#d63031`
   - 跌/利空 → 绿色 `#27ae60` 或 `#00b894`
   - 中性/标题 → 深蓝 `#2c3e50`
   - 背景 → 浅灰 `#f5f6fa`，卡片白 `#ffffff`
   - 风险提示 → 橙黄 `#e17055` 背景 `#ffeaa7`

2. **排版**：
   - 字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
   - 标题层级清晰，一级标题 24px+，二级标题 18-20px，正文 14-16px
   - 行高 1.6-1.8，段落间距适当

3. **数据呈现**：
   - 指数涨跌用表格呈现，涨跌数字带颜色（红涨绿跌）
   - 资金流向用表格，净流入红色，净流出绿色
   - 板块涨跌用卡片或列表，标注涨跌方向
   - 关键价位用表格，压力位红色标注，支撑位绿色标注
   - 风险提示区域用醒目底色区分

4. **页面结构**（自上而下）：
   - 报告头部：标题（日期+星期）
   - 一、大盘整体复盘（指数表格 + 量能 + 情绪指标）
   - 二、资金流向（北向 + 主力 + 龙虎榜）
   - 三、板块涨跌详情（领涨/领跌/轮动）
   - 四、技术面分析（关键价位表 + 通道判断）
   - 五、风险提示 + 明日预判
   - 页脚：免责声明 + 生成时间

### 免责声明

页面底部必须包含：
> 本报告仅供参考，不构成投资建议。股市有风险，投资需谨慎。数据来源于公开市场信息，力求但不保证信息的准确性和完整性。

## 工作流

### Step 1: 确定复盘日期

- 默认复盘"今日"（如果当前时间在 15:00 之后）
- 如果当前时间在 15:00 之前，复盘"昨日"
- 用户可指定具体日期

### Step 2: 获取数据

按五大维度逐一获取数据：

1. **指数行情**：使用 tdx-connector 的 `tdx_quotes` 或 `tdx_kline` 获取主要指数收盘数据
2. **量能数据**：从指数行情或 WebSearch 获取两市成交额
3. **市场情绪**：WebSearch 搜索"今日涨停数量 炸板率 连板高度"等
4. **资金流向**：WebSearch 搜索"今日北向资金 主力资金流向"
5. **板块涨跌**：WebSearch 搜索"今日板块涨跌 领涨板块 领跌板块"
6. **龙虎榜**：WebSearch 搜索"今日龙虎榜"
7. **技术面**：基于指数K线数据自行计算关键价位

### Step 3: 分析整合

- 将获取的原始数据按五大维度组织
- 撰写盘面特征描述、情绪研判、量价关系分析
- 计算支撑位/压力位（基于近期高低点、均线、整数关口）
- 形成明日预判逻辑链

### Step 4: 生成 HTML

- 按 HTML 报告生成规范创建单页 HTML
- 将所有数据填充到对应模块
- 确保配色正确（红涨绿跌）
- 输出到工作目录

### Step 5: 呈现结果

- 使用 present_files 展示 HTML 文件
- 提供简要复盘摘要

## 数据缺失处理

- 某个维度数据无法获取时，在该模块标注"数据暂缺"并说明原因
- 不要编造数据
- 北向资金数据：2024年8月起改为季度披露，日常无法获取实时数据时标注说明
- 龙虎榜数据：收盘后约17:00-18:00才有完整数据，如复盘时间较早则标注"数据尚未更新"

## 与其他技能的关系

- **overnight-global-market-review**：隔夜海外市场及重要资讯由该技能独立负责，本技能不包含此内容
- **组合使用**：如需完整复盘（含隔夜海外），请先运行 overnight-global-market-review，再运行本技能

## 复盘质量标准

- 所有数字必须有来源，不编造
- 涨跌判断必须基于实际数据
- 预判部分必须基于当日盘面推导，不空泛
- 报告总字数建议 1500-3000 字，详略得当
