# 产品四性详解

收益、波动、期限、复杂度是描述任何金融产品都绕不开的四个**独立正交**维度——一个产品可以高收益+低波动+长期限+高复杂度（优秀对冲基金），也可以低收益+低波动+短期限+低复杂度（货币基金）。正交保证「产品价值翻译」没有遗漏。

每一性都按 `内涵 → 衡量维度 → 客户价值` 三层展开。客户价值是把客观特征翻译为主观价值的关键，也是 Phase 2 反推画像的起点。

## 3.1 收益 · Return
- **内涵**：产品创造财务回报的能力——多少、多稳、多久能拿到。
- **衡量维度**：历史年化收益率；相对基准超额收益；胜率与赔率；收益分布形态；费后净收益；税后净收益。
- **客户价值**：
  - 帮助客户达成具体财务目标（金额 × 期限）
  - 跑赢通胀，实现真实购买力增长
  - 提供期望中的现金流（分红/利息）
  - 通过复利放大长期财富

## 3.2 波动 · Volatility
- **内涵**：产品净值上下起伏的幅度与风险来源——会让客户多担心、多难受。
- **衡量维度**：年化波动率；最大回撤幅度；回撤恢复周期；压力情境下的极端表现；风险来源（市场/信用/流动性/汇率）。
- **客户价值**：
  - 匹配客户的心理承受边界，避免半途下车
  - 避免在低点恐慌赎回造成实亏
  - 通过低相关资产改善组合稳定性
  - 让客户睡得着觉

## 3.3 期限 · Term
- **内涵**：产品的持有时间属性与资金锁定特征——多久能用、多久不能动。
- **衡量维度**：建议持有期；强制锁定期；流动性窗口（开放频率）；赎回到账时效；复利生效所需时长。
- **客户价值**：
  - 与客户资金使用周期匹配，避免错配
  - 为长期复利提供「时间」原料
  - 强制客户脱离短期噪音、获取长期收益
  - 为人生大事（养老、教育、传承）做时点对齐

## 3.4 复杂度 · Complexity
- **内涵**：产品结构与运作机制的理解门槛——客户看不看得懂、敢不敢拿住。
- **衡量维度**：底层资产可解释程度；结构层数（嵌套/衍生/分级）；策略可观察度；信息披露质量；退出机制清晰度。
- **客户价值**：
  - 在客户认知边界内提供选择，避免买了不懂的东西
  - 让客户在波动中能「知道为什么」而不慌
  - 让客户能持续监督和判断是否调整
  - 随客户成长打开更高阶产品的大门，提供可控感与安全感
