# A股市场情绪日报（龙虎榜+题材热点+行业轮动）

## 适用场景

- 交易日收盘后（15:00 之后，龙虎榜数据通常 17:00 前更新）生成当日短线情绪复盘
- 用户询问当日龙虎榜、游资动向、热门题材、行业轮动

## 工作流

1. **确定交易日期**
   - 默认最近交易日。盘中（15:00 前）运行需提醒用户龙虎榜为 T 日盘后数据。
   - 传入日期格式 `YYYY-MM-DD`；若该日非交易日或数据未更新，东财龙虎榜接口返回空，脚本会尝试向前回溯最近 5 天找有数据的交易日。

2. **运行生成脚本**

   ```bash
   python scripts/build_report.py --date 2026-08-13 --out ./市场情绪日报-2026-08-13.html
   ```

   - `--date` 可省略，省略时自动取今天并向前回溯找最近有数据的交易日。
   - `--out` 输出路径，默认 `./市场情绪日报-<日期>.html`。
   - 依赖仅 `requests`（Python 3.9+，若提示 ModuleNotFoundError 则 `pip install requests`）。

3. **脚本内部数据来源（三路，全部为真实公开接口）**
   - **全市场龙虎榜**：东财 datacenter `RPT_DAILYBILLBOARD_DETAILSNEW`，按 `BILLBOARD_NET_AMT` 降序，含代码/名称/涨跌幅/净买入额/上榜原因/换手率。东财请求全部走 `em_get()` 限流（间隔≥1s+随机抖动），勿绕过。
   - **题材热点**：同花顺强势股归因接口 `zx.10jqka.com.cn/event/api/getharden/`（零鉴权），取 `reason` 字段按「+」拆词做词频统计，得出 TOP 题材及出现只数。
   - **行业轮动**：东财 push2 clist `fs=m:90+t:2`，行业板块涨跌幅排名，含上涨/下跌家数与领涨股。

4. **输出规范（脚本已内置，勿改动）**
   - 单文件 HTML、资源全内联、可离线打开，无外部 CDN/字体依赖。
   - 暗色盘面复盘风（深底色 #0d1117 系，红 #f0334b 涨 / 绿 #00b578 跌——A股惯例）。
   - 金额统一 `¥`，≥1 亿用「亿」，否则「万」。
   - 内联 SVG：题材热度条形图（TOP15）、行业涨跌榜（前10涨+后10跌）、龙虎榜净买入 TOP20。
   - 页脚注明数据来源（东方财富龙虎榜/同花顺热点/东财行业板块）与实际交易日期。

5. **完成后**
   - 用 present_files 把 HTML 交给用户预览。
   - 口头摘要：上榜家数、净买入合计、最热题材 TOP3、领涨/领跌行业，一句话点评情绪温度。

## 注意

- 龙虎榜净买入可能为负（净卖出），图表需红绿双向展示。
- 同花顺题材接口周末/节假日返回空属正常，脚本回溯逻辑会处理；若连续 5 天为空再报错。
- 若用户需要大盘指数/量能/隔夜外盘等综合复盘，改用 `a-share-daily-review` 技能。
