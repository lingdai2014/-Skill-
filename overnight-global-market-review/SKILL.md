# 隔夜海外市场复盘技能

## Overview

本技能提供隔夜海外市场行情与重要资讯的复盘工作流：从数据获取、多维度分析到生成单页 HTML 复盘报告。覆盖美股、亚太期货、大宗商品、汇率、国内外重要资讯，帮助用户在A股开盘前快速掌握隔夜全球动态。

## 复盘时间

- **最佳时点**：每日早间 7:00-9:30（A股开盘前），覆盖前一交易日美股收盘至当日早间亚太市场
- **也可用于**：A股收盘后复盘当日隔夜数据（作为完整A股复盘的一部分）

## 数据源优先级

1. **WebSearch** — 主要数据获取方式，搜索各维度最新数据
2. **WebFetch** — 补充抓取东方财富、同花顺等公开数据页面
3. **通达信 MCP** — 可获取部分期货/指数K线数据

## 复盘五大维度（固定框架）

### 一、美股三大指数

**必须包含的指数：**
- 道琼斯工业指数：收盘点位、涨跌幅、涨跌点、盘中走势描述
- 标普500指数：收盘点位、涨跌幅、涨跌点、盘中走势描述
- 纳斯达克综合指数：收盘点位、涨跌幅、涨跌点、盘中走势描述

**增强信息：**
- 标普500十一大板块涨跌分布
-  notable 个股异动：科技巨头（苹果/微软/谷歌/亚马逊/Meta/英伟达/特斯拉）、中概股（纳斯达克中国金龙指数）
- 芯片股/费城半导体指数表现
- 盘后期货走势（如有重大财报或事件）

**搜索关键词建议：**
- "昨夜美股收盘 道琼斯 标普500 纳斯达克"
- "美股 科技股 中概股 涨跌"

- 恒生指数期货夜盘：收盘价、涨跌幅、升水/贴水点数

### 五、隔夜&早间重要资讯汇总

**1. 国内宏观、财经、政策消息**
- 国务院/央行/各部委政策发布
- 重要经济数据（CPI/PPI/PMI/社融/M2等）
- 重要会议纪要或领导讲话

**2. 行业产业利好/利空新闻**
- 重点行业动态（新能源/半导体/医药/消费等）
- 券商研报核心观点
- 产业链重大变化（涨价/缺货/技术突破等）

**3. 重磅个股公告**
- 重大投资/并购/重组
- 业绩快报/预告（超预期或暴雷）
- 停牌/复牌/新股上市
- 重要股东增减持

**4. 海外财经大事**
- 美联储动态（利率决议/官员讲话/经济数据）
- 地缘政治（中美关系/中东局势/俄乌等）
- 重要经济数据发布时间预告
- 其他央行动态（欧洲央行/日本央行等）

**搜索关键词建议：**
- "今日财经新闻 政策公告"
- "美联储 最新动态"
- "个股公告 重大事项"

## HTML 报告生成规范

### 技术规范

1. **单文件自包含**：所有 CSS 内联在 `<style>` 标签中，不引用外部资源
2. **零依赖**：不使用任何 CDN 链接、外部字体、外部 JS 库
3. **响应式**：适配桌面端浏览，最大宽度 1200px，居中
4. **文件命名**：`隔夜海外复盘_YYYYMMDD.html`，如 `隔夜海外复盘_20260812.html`
5. **字符编码**：UTF-8，声明 `<meta charset="UTF-8">`

### 视觉规范

1. **配色方案**：
   - 涨/利好 → 红色 `#e74c3c` 或 `#d63031`
   - 跌/利空 → 绿色 `#27ae60` 或 `#00b894`
   - 中性/标题 → 深蓝 `#2c3e50`
   - 背景 → 浅灰 `#f5f6fa`，卡片白 `#ffffff`
   - 原油/能源 → 橙色 `#e17055`
   - 贵金属 → 金色 `#f39c12`

2. **排版**：
   - 字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
   - 标题层级清晰，一级标题 24px+，二级标题 18-20px，正文 14-16px
   - 行高 1.6-1.8，段落间距适当

3. **数据呈现**：
   - 指数/商品涨跌用表格，涨跌数字带颜色（红涨绿跌）
   - 板块异动用卡片或标签呈现
   - 重要资讯用列表，每条一行
   - 可在页面顶部增加"隔夜要闻速览"卡片，3-5句话概括核心信息

4. **页面结构**（自上而下）：
   - 报告头部：标题（日期+星期+复盘区间）
   - 隔夜要闻速览（3-5条核心信息）
   - 一、美股三大指数（含板块/个股异动）
   - 二、A50/恒指期货隔夜表现
   - 三、大宗商品（原油+贵金属+可选基本金属）
   - 四、美元指数、人民币汇率
   - 五、隔夜&早间重要资讯汇总（宏观/行业/个股/海外）
   - 页脚：免责声明 + 生成时间

### 免责声明

页面底部必须包含：
> 本报告仅供参考，不构成投资建议。数据来源于公开市场信息，力求但不保证信息的准确性和完整性。

## 工作流

### Step 1: 确定复盘日期

- 默认复盘"昨夜"（前一交易日美股收盘 → 当日早间）
- 用户可指定具体日期

### Step 2: 获取数据

按五大维度逐一获取数据：

1. **美股行情**：WebSearch 搜索"昨夜美股收盘 道琼斯 标普500 纳斯达克"
2. **A50/恒指期货**：WebSearch 搜索"富时A50期货夜盘 恒指期货夜盘"
3. **大宗商品**：WebSearch 搜索"国际油价 黄金 白银 收盘"
4. **汇率**：WebSearch 搜索"美元指数 人民币汇率 中间价"
5. **重要资讯**：WebSearch 搜索"今日财经新闻 政策公告 美联储"

### Step 3: 分析整合

- 将获取的原始数据按五大维度组织
- 撰写盘中走势描述、板块异动分析
- 提炼隔夜要闻速览（3-5条核心信息）
- 分析对A股的潜在影响

### Step 4: 生成 HTML

- 按 HTML 报告生成规范创建单页 HTML
- 将所有数据填充到对应模块
- 确保配色正确（红涨绿跌）
- 输出到工作目录

### Step 5: 呈现结果

- 使用 present_files 展示 HTML 文件
- 提供简要复盘摘要

## 数据缺失处理

- 某个维度数据无法获取时，在该模块标注"数据暂缺"并说明原因
- 不要编造数据
- A50/恒指期货数据：夜盘收盘较早（约凌晨1:00），早间复盘时应已更新
- 部分大宗商品数据可能因合约换月导致价格跳变，注意标注合约月份

## 与其他技能的关系

- **被 a-share-daily-review 调用**：作为A股完整复盘的子模块，提供第四、五维度数据
- **独立使用**：早间快速了解隔夜全球动态，不依赖A股数据
- **数据输出**：各维度数据结构化组织，方便被其他技能引用

## 复盘质量标准

- 所有数字必须有来源，不编造
- 涨跌判断必须基于实际数据
- 资讯部分必须注明来源和时间
- 报告总字数建议 1000-2000 字，简洁有力
